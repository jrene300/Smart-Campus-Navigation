TEST RESULTS - Project 2: Smart Campus Navigation and Facility Analytics System

How we tested:
  Build:  g++ -std=c++11 -Iinclude src/*.cpp -o campus
  M1 build (10-option menu):  g++ -std=c++11 -DMILESTONE1 -Iinclude src/*.cpp -o campus
  Run:    ./campus            (uses data/)
          ./campus testdata/collision   (uses our own test folder)
  Menu numbers below are from the Final menu.

NOTE: These results were run on a Linux machine. We still need to
re-run everything on the CELL machines and update this file.

Each test: number, description, input, expected, actual, pass/fail

-----------------------------------------------------------------
FILE LOADING
-----------------------------------------------------------------

Test 1 - Load the sample files
  Input:    data/
  Expected: 7 / 6 / 10 / 7 accepted, 0 rejected
  Actual:   7 / 6 / 10 / 7 accepted, 0 rejected. Hash capacity 11,
            entries 10, collisions 1.
  Result:   PASS

Test 2 - Bad records, Windows line endings, spaces, lowercase ID, # in name
  Input:    testdata/messy
  Expected: Warning with file, line number and reason for each bad line.
            f004 is stored as F004. "Room #5" keeps its #.
  Actual:   All of these were rejected with a warning: duplicate building,
            duplicate / reversed / self / unknown / 3-field connection,
            bad ID, empty field, unknown building, duplicate department,
            unknown parent. f004 stored as F004 and "Room #5" kept.
  Result:   PASS

Test 3 - Missing files
  Input:    testdata/missing
  Expected: Error for each file, no crash, empty messages in the menu.
  Actual:   Error printed for each file and the program kept running.
  Result:   PASS

Test 4 - Empty files
  Input:    testdata/empty
  Expected: 0 accepted for every file, empty messages, tree stats 0 / 0 / N/A.
  Actual:   Same as expected.
  Result:   PASS

-----------------------------------------------------------------
HASH TABLE AND SEARCH
-----------------------------------------------------------------

Test 5 - Search by ID
  Input:    F004, f004, 004, F999
  Expected: Found, found, invalid format message, not found (shows F999).
  Actual:   Same as expected.
  Result:   PASS

Test 6 - Hash collision and duplicate key
  Input:    testdata/collision (F001, F013, F025 land in the same bucket,
            and f013 is a duplicate)
  Expected: Collisions = 2. The duplicate is rejected and does not
            change the collision count.
  Actual:   "3 accepted, 1 rejected (capacity 11, entries 3, collisions 2)"
  Result:   PASS

Test 7 - Search by name and by category
  Input:    "room 101", " classroom "
  Expected: 2 matches for the name, 3 matches for the category (ignores
            capital letters and outer spaces).
  Actual:   Same as expected.
  Result:   PASS
